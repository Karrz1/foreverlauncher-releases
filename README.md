# foreverlauncher-releases

**ForeverLauncher is retired.** Its last version here, 2.6.0, keeps working, but it gets no more updates.

Use the **WoW Forever launcher** instead. It joins any server, also one you built yourself, and on its first start it
takes over your ForeverLauncher servers, game folder and language:

### [Download the WoW Forever launcher](https://github.com/Karrz1/Karrz-playerbots-wow-forever/releases/latest/download/WoWForeverLauncher.exe)

Put `WoWForeverLauncher.exe` in any folder, start it, pick join and enter the server's address. It also works under
Wine/Proton on Linux.

- Your own server with bots: the full repack on the [latest release](https://github.com/Karrz1/Karrz-playerbots-wow-forever/releases/latest).
- Help and news: [Discord](https://discord.gg/eJt62dDh54).

The old ForeverLauncher builds below stay for history (signed, no source code).
